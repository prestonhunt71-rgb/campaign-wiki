# Revision 3.0.24 — Configurable Wording and Current Status

- Add a **Custom Relationship Wording** settings menu without changing stored Article relationships.
- Preserve the current world's **Owns / Owned By** and **DNPCs / DNPC of** terminology through one-time settings initialization.
- Use the original Campaign Wiki relationship labels as factory defaults for new worlds.
- Apply ownership wording to Actor or Affiliation relationships with Places, Vehicles, Equipment, and MacGuffins while leaving other categories unchanged.
- Add **Current Status** to all Article forms and display it beneath Article artwork before Aliases and First Appearance.
- Default Current Status to Active without rewriting existing Article data; support Active, Inactive, Retired, Unknown, Missing, Incarcerated, Deceased, Destroyed, and Disbanded.
- Fix Article Linking Categories so choices cascade downward while child overrides never change their parents.
- Record the deferred system-neutral World Profile and in-app documentation direction in the version 4 planning document.

Existing databases, relationships, visibility, linking-category selections, sorting, relationship depths, artwork paths, and page settings are preserved.
