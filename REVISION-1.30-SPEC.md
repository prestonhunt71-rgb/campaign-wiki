# Campaign Wiki 1.30

This release adds universal visual article linking.

- **Link To** is a directional relationship selected on a source article.
- **Linked From** is generated automatically on the destination article.
- The destination displays linked source articles as clickable thumbnails.
- Thumbnails work between every article type and are separated into responsive,
  alphabetized sections by top-level source category.
- Linked articles without an image receive a visible link placeholder.
- Public/GM projection prevents private linked articles from appearing to
  players.
- Static HTML exports use the same grouped galleries and navigation behavior.

The release also includes the v1.29 category-scoped relationship picker and
looping Previous / Next folder navigation.
