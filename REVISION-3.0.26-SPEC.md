# Revision 3.0.26 — Foundry Source Recovery and GM Overview

- Add a GM-only **GM-Only Articles** home-page section containing every Article explicitly set to Always GM Only.
- Add a persistent **Recover Foundry Sources** action beneath Needs Actioning.
- Add a contextual **Relink** action to Missing Foundry Source entries.
- Let GMs relink an existing Wiki Article to a replacement Foundry Actor or Scene.
- Let GMs selectively recreate deleted Wiki Articles for existing unlinked Foundry Actors and Scenes.
- Recreated Articles begin beneath People or Places and enter Needs Actioning for review.
- Reject duplicate source links and duplicate Article titles without changing unrelated records.
- Make recovery opt-in: opening the recovery window or leaving entries unselected changes nothing.

Existing databases, relationships, visibility, settings, artwork, and Foundry documents are preserved.
