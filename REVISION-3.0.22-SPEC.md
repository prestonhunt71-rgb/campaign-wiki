# Revision 3.0.22 — Independent Automatic-Link Controls

- Add an **Automatic Article Linking** world setting to enable or disable first-mention body links.
- Add a separate **Article Linking Depth** world setting with distances from one through five relationship steps.
- Default automatic linking to enabled at two steps without changing relationship-card display settings.
- Traverse parent and child relationships in both directions for linking, allowing paths such as Session → character → affiliation.
- Continue filtering hidden targets before matching player-visible text.
