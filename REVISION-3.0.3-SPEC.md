# Revision 3.0.3 — Section-Clean Navigation

- Keep every Article relationship stored without rendering every relationship as a sidebar branch.
- Limit each top-level menu to Articles whose canonical primary path belongs to that section.
- Show Arcs beneath Metaplots without expanding those Arcs into Sessions.
- Show Sessions beneath Arcs without expanding into referenced People, Places, or Images.
- Keep People, Places, and Images confined to their own canonical section.
- Make sidebar counts reflect only entries that can be displayed in that branch.
- Sort all Metaplot- and Arc-related navigation newest first using direct or derived dates.
- Place undated entries after dated entries and use titles as stable tie-breakers.
